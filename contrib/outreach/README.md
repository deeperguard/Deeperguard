# Deeperguard notes outreach

Machine-readable outreach copy lives at **`/api/promo`** on production (`https://www.deeperguard.com/api/promo`).

Run the promotion helper from the repo:

```bash
./scripts/promote-notes-everywhere.sh
```

Generated text files are written to `contrib/outreach/generated/` (gitignored if you add them to `.gitignore`).

Post manually on Reddit, Hacker News, Product Hunt, and directory sites — follow each community’s rules and disclose that the product is in public beta.
