Deeperguard

HTTPS needs the Deeperguard certificate on this device

If Safari shows a certificate warning or the app will not open, install and trust the LAN CA, then open the secure link.

  1. Tap Install certificate and allow the profile download.
  2. On iPhone: Settings → Profile Downloaded → Install.
  3. Then Settings → General → About → Certificate Trust Settings and enable Deeperguard CA.
  4. Return here and open Notes over HTTPS.
