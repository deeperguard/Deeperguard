Install

Download Deeperguard

Deeperguard is an installable web app. There is no app-store download. Open {{ app_url }} in your browser, then add it to your home screen.

iPhone and iPad

  1. Open the notes app in Safari.
  2. Tap the Share button.
  3. Tap Add to Home Screen, then Add.

The icon opens the vault full screen, including offline after you have unlocked it once on that device.

Android

  1. Open the notes app in Chrome.
  2. Tap the menu, then Install app or Add to Home screen.

If Chrome offers an install banner, that is the same step.

Mac, Windows, and Linux

  1. Open the notes app in Chrome, Edge, or another Chromium browser.
  2. Click the install icon in the address bar, or use the browser menu → Install Deeperguard.

Safari on Mac can use File → Add to Dock after you open the app.

Already installed?

Open the home-screen icon, or go straight to {{ app_url }}. Sign in, then unlock the vault with your vault password.
