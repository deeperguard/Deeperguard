AI chat (optional)

        

          
Less private. Chat sends the text of the note you have open (and, if enabled, its scanned text) from this browser to the Ollama server below. That text leaves the end-to-end encrypted vault. Nothing else is sent: no other notes, tags, file names, e-mail address or passwords. With your own Ollama server the browser talks to it directly. With Ollama Cloud the Deeperguard server relays the request to ollama.com (browsers cannot call it directly); the relay forwards and forgets, it stores neither your key, the prompt nor the answer. Ollama Cloud states it processes prompts transiently and never logs or trains on them. Do not use it on notes you would not paste into a chatbot.

          
          
Leave empty for Ollama Cloud. For your own server enter its URL (it must be reachable over HTTPS from this browser and allow this origin via OLLAMA_ORIGINS).

          
          
Create a key at ollama.com/settings/keys. It is stored inside your encrypted vault and synced to your other devices; it is never saved unencrypted on this device.

          
          
Default is the cloud model gpt-oss:120b. Any model from ollama.com's cloud library works; on your own server use a model you have pulled.

      Checking signed release…
      
          
      
          
      After load, the browser re-fetches same-origin assets from client-manifest.json, hashes them with SubtleCrypto (canonical manifest_sha256 form), and compares that computed value to manifest_sha256 on the GitHub Release{% if release_tag %} {{ release_tag }}{% endif %} (public Releases API — not this server). The shell meta above is only a convenience mirror; a mismatch with the computed hash is flagged. A match proves the hashed assets equal that release’s published hash — not Sigstore verification. Loaded <script>/<link> URLs are cross-checked against the manifest (unlisted assets fail the check). Requests time out rather than hanging. This checker script is itself served by the same origin, so independent verification still means cosign or rebuilding from source (see /verify).{% if release_signed %} This release publishes a Sigstore bundle.{% endif %}
